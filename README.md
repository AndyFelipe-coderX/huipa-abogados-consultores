# Juipa & Asociados · Abogados y Consultores

Sitio web del estudio jurídico **Juipa & Asociados**, dedicado exclusivamente a la defensa de **personas naturales**. Las consultas de personas jurídicas se derivan a la firma aliada.

## Áreas de práctica
- Derecho Penal y Procesal Penal
- Derecho Policial
- Derecho Constitucional
- Derecho Sancionador y Disciplinario
- Derecho Civil y Procesal Civil
- Derecho Laboral
- Litigación Oral

## Stack
- React 19 + Vite
- Tailwind CSS v4 (tema día/noche con variables CSS)
- Motion (animaciones discretas, respeta "reducir movimiento")
- Fuentes autoalojadas: Fraunces (serif) e Inter (sans)
- Lucide (iconos)

## Editar contenidos
Todo el texto, teléfonos y áreas están en `src/data/site.js`.
**Antes de difundir la web, reemplazar el teléfono, WhatsApp y correo de ejemplo.**

## Desarrollo
```bash
npm install
npm run dev
```

Cada `git push` a `main` vuelve a desplegar en Vercel automáticamente.
